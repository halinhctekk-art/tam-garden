# 🌱 Khu vườn của Tâm

Một game trồng cây giản đơn nhưng vô cùng vui vẻ!

## 🎮 Cách chơi

1. **Mua hạt giống** từ cửa hàng (🏪)
   - 🍅 Cà chua: 50💰
   - 🥕 Cà rốt: 40💰
   - 🌻 Hoa hướng dương: 60💰
   - 🌽 Ngô: 45💰

2. **Tưới nước** cho cây mỗi ngày bằng cách click vào cây

3. **Thu hoạch** khi cây sáng (🌟) và nhận tiền

4. **Lặp lại** - Mua thêm hạt giống và tiếp tục!

## 📊 Thông tin cây

| Cây | Giá | Thu hoạch | Ngày mọc |
|-----|-----|----------|---------|
| 🍅 Cà chua | 50 | 120 | 3 |
| 🥕 Cà rốt | 40 | 100 | 3 |
| 🌻 Hoa hướng dương | 60 | 150 | 4 |
| 🌽 Ngô | 45 | 110 | 3 |

## 🎯 Mục tiêu

- Kiếm càng nhiều tiền càng tốt
- Xây dựng vườn rau ngập ngửa
- Tận hưởng trò chơi!

## 📁 Cấu trúc file

- `index.html` - Giao diện game
- `style.css` - CSS styling
- `script.js` - Game logic

## 🚀 Chạy game

1. Tải file
2. Mở `index.html` bằng trình duyệt
3. Bắt đầu chơi!

## 💡 Tips

- Hoa hướng dương cho lợi nhuận cao nhất (150💰)
- Nhưng mất lâu hơn (4 ngày)
- Cà rốt rẻ nhất để bắt đầu
- Tưới nước mỗi ngày để cây phát triển nhanh
